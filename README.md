# PM & AI PM Coursebook

A plain-language, always-updated course book on Product Management (Part A) and AI Product Management (Part B).

**Read it:** https://sgunisity.github.io/pm-coursebook/

- Chapters are Markdown files in `docs/`. The site is built with MkDocs Material and published by GitHub Actions.
- `MASTER_PROMPT.md` holds the instructions the scheduled Claude runs follow.
- `state/progress.json` tracks which chapters are written.
- Changes are listed on the site's What's New page.
